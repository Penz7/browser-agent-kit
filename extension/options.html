Browser Agent Kit

Must match BROWSER_KIT_PORT of the MCP server (default 7851).
If set, the MCP server must be started with the same BROWSER_KIT_TOKEN.
"example.com" also matches its subdomains. "*" allows everything.
Dialogs block all browser events, so the kit always closes them automatically.
Real mode sends trusted mouse/keyboard events and captures console/network while attached. Fast mode avoids the "is debugging this browser" bar but uses synthetic events some sites ignore.
0 keeps it attached (needed if you want console/network capture to run continuously).
