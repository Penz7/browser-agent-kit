Browser Agent Kit đã cài

Cho phép AI agent (Codex, Claude Code, Antigravity, Cursor…) điều khiển Chrome này.

Đang kiểm tra kết nối…

Server MCP sẽ tự chạy khi agent của bạn khởi động. Chạy browser-agent-kit doctor trong terminal để kiểm tra bất cứ lúc nào.

Cho phép site

Agent chỉ thao tác được trên site bạn cho phép. Mở site đó, bấm icon extension, chọn Allow this site. Hoặc:

Thử ngay
  1. Mở agent của bạn (Antigravity, Codex, Claude Code…).
  2. Ra lệnh: Mở tab mới, vào example.com, đọc tiêu đề trang.
  3. Tab mới sẽ nằm trong group Agent, viền tím sáng khi agent đang thao tác, nút Dừng ở thanh trên.
